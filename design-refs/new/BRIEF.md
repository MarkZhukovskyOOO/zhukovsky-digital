## Проект
- React 19 + Vite, JS (не TS), react-router-dom. Корень: `/Users/aleksandr/Desktop/mark`.
- Компоненты: `src/components/*.jsx` + парный `.css`. Страницы: `src/pages/`.
- Токены дизайн-системы в `src/index.css`: light на `:root`, dark на `[data-theme="dark"]`.
  Бренд #0071e3, шрифт Onest, контейнер 1240px (gutter 100/40/20), радиусы xs–2xl+pill,
  тени, статусные цвета. Есть легаси-алиасы `--ink/--muted/--line/--bg-soft/--blue/--radius`.
- Тёмная тема обязана продолжать работать: используй ТОЛЬКО токены (var(--...)),
  никаких хардкодов цветов, кроме случаев когда цвет одинаков в обеих темах.

## Ассеты нового дизайна (всё в `/Users/aleksandr/Desktop/mark/design-refs/new/`)
- `<frame>.png` — полный рендер фрейма 1x. Имена: landing-1440/768/375, case-energo-*,
  service-mobile-*, company-*, cases-*, modal-*, menu-mobile-*, dropdown-*, policy-*, notfound-*, carousel-1440.
- `slices/<frame>-sNN.png` — те же макеты полосами по 1400px (шаг 1300, перекрытие 100px).
  ЧИТАЙ СЛАЙСЫ, а не полные PNG — полные при чтении сжимаются и теряют детали.
- `frames/<frame>.json` — полное поддерево Figma-узлов фрейма (координаты, цвета, шрифты,
  радиусы, отступы). Точные значения бери отсюда (python3 + json, узлы по name).
- `frames/<frame>.txt` — все тексты фрейма по порядку с размером/весом шрифта. Копирай тексты 1:1 отсюда.
- `images/<ref>.png` — оригиналы картинок-заливок; `images/USAGE.txt` — где какая используется.
- `crop_node.py` — вырезать узел из PNG фрейма:
  `python3 design-refs/new/crop_node.py landing-1440 --list 3` — список узлов с координатами;
  `python3 design-refs/new/crop_node.py landing-1440 "<имя или id узла>" out.png [pad]` — кроп.
  Используй для сложных визуалов (телефонные мокапы и т.п.) → клади в `src/assets/figma/`.

## Правила
1. Тексты — строго из `frames/*.txt`, не сочинять.
2. Брейкпоинты: макеты есть для 1440 / 768 / 375. На 768 сохраняются многоколоночные
   раскладки (сверяйся с фреймом *-768!); полное схлопывание в столбик — только к ~375.
   Планшетные правила клади в @media (max-width: 860px), мобильные — в @media (max-width: 560px).
3. Section Header в секциях: только title + description (+ иногда ссылка-действие справа),
   БЕЗ оверлайнов/эйбрау, если их нет на слайсе.
4. Не трогай `src/index.css` (токены) без крайней необходимости — все стили в css компонента.
5. Не трогай чужие файлы (см. своё задание). `Header.jsx` меняет только задача «хедер».
6. Картинки: оригиналы из `images/` копируй в `src/assets/figma/` с осмысленным именем
   и импортируй. Сложные векторные композиции — кропь из PNG через crop_node.py (1x, позже заменим на 2x).
7. Проверка: `npm run build` обязан проходить без ошибок. Дев-сервер не запускать.
8. Хвостовая пунктуация списков («;», «.») — как в макете.
